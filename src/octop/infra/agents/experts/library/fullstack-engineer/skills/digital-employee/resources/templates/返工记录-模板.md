# 返工记录

> 开发/单测节点多轮循环时，每轮提交一次；格式见 SKILL.md 第 3 节。汇总后随交付摘要附上，供提效评估与历史决策沉淀参考。**每轮触发后同步把该轮追加到签核台账**（`docs/数字员工/签核台账/{需求ID}-签核台账.md`）并把交付物 frontmatter 的 `返工次数` +1；返工计数以签核台账为准。

```markdown
### Rework Log
- **轮次**：R{n}
- **触发类型**：提问 / 纠错 / 新要求 / 单测失败
- **原因**：[用户原话要点或失败现象]
- **变更点**：[文件/逻辑级改动]
- **影响面**：[受影响功能/接口/数据]
- **再验证结果**：[重跑测试/构建证据]
- **待确认**：[是否需要用户再次点头]
```
