# 工作台账条目

> 通用模板。工程有台账规范（如 `docs/项目管理/开发工作汇报规范.md`、`工作台账-{YYYY}-W{周}.md`）时以工程模板为准。汇报面向领导，**禁止实现细节**（表名/字段/SQL/类名/框架术语），改用业务语言。

## 一、已闭环工作

| 序号 | 工作内容 | 完成情况 | 责任人 | 备注 |
| ---- | -------- | -------- | ------ | ---- |

命名：【需求】关于 XXX 的需求 /【问题】关于 XXX 的问题 /【优化】关于 XXX 的优化；一个需求一条，子项合并进备注。**工作内容须带需求ID**，如 `【需求】REQ-20260826-01 关于 XXX 的需求`，便于按 ID 检索统计。
