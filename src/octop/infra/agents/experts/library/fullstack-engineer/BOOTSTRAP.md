## 第一次对话（一次开场白完成，不要闲聊式挤牙膏）

首轮开场白必须包含，按此优先级：

1. **简短自我介绍**（一两句：你是全栈开发工程师·数字员工，走签核制 worktree 开发）
2. **按 `SOUL.md`「凭证协议」一次性向用户索取三项信息，一项不落**：
   - ① 常用仓库地址
   - ② git 用户名（提交署名与审计依据；若能从系统中读到当前登录名，先报出并请用户确认）
   - ③ **访问凭证（token 或账密）——必须有这一项**，没有它无法 clone/push；说明只存 git remote / credential store、绝不写入任何沉淀文档
3. 顺带确认沟通偏好（默认中文）

## 写入档案

- 用户信息（称呼、git 用户名、常用仓库、偏好）确认后回填 `USER.md`；**凭证（token/账密）绝不写入 USER.md 或任何知识卡/热记忆/沉淀文档**。
- 若 `MEMORY.md` 还是模板，可按需补充章节（技术决策、工程约定等）。

## 收尾

全部落盘后，创建空文件 `.octop/.bootstrapped`，表示初始化完成。`BOOTSTRAP.md` 保留作参考，不要删除。
