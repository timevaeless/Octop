```text
              ┌──────────────────────────────┐
```

## v1 · 执行/Web 分离（阶段 2）

日期：2026-09 · commit：c87304d1

```text
                    ┌─────────────────────────────────────────┐
   用户请求 ───────►│  api 节点（只能 1 个，多开必出事）          │
                    │                                         │
                    │  HTTP/SSE ◄── 入队 ──► procrastinate     │
                    │       │                    │            │
                    │       │ 每路流 2 个专用连接   │            │
                    │       │ (LISTEN+SELECT)     │            │
                    │  cron 调度器 ── 直接 boot ──┐            │
                    │  IM 轮询器  ── 直接 boot ──┤ 全部就地跑  │
                    │  主动关怀   ── 直接 boot ──┘            │
                    └────────────────┬────────────────────────┘
                                     │ PG 队列
                    ┌────────────────▼────────────────┐
                    │  agent-worker ×N                 │
                    │  (内部 OctopServer 也抢后台单例 ✗)│
                    │  turn_events 只增不删 ✗          │
                    └─────────────────────────────────┘

   痛点：api 多副本会重复跑后台；worker 抢主；连接数 O(并发流)；
        冷启动并发会建多个连接池；turn_events 无限增长
```

## v2 · 多副本集群 + 选主（阶段 3，当前）

日期：2026-09-25 · commit：1e40cc9e / 1214ea19

```text
                          ┌──────────────────┐
   用户请求 ─────────────►│  nginx LB         │  ★ 新增（SSE 无缓冲
                          └────┬────────┬─────┘    + Last-Event-ID）
                          ┌────▼───┐┌───▼────┐
                          │ api #1 ││ api #2 │   ★ 可横向复制
                          └───┬────┘└───┬────┘
              ★ BackgroundGate│         │（server.py 接线收敛成
              （cluster 包内） │         │  4 行 gate.route）
                 ┌────────────▼──┐  ┌───▼────────────┐
                 │ LeaderRunner   │  │ LeaderRunner    │
                 │ ★抢 PG 事务级锁 │  │ ★待命，班长挂   │
                 │ ★TCP keepalive │  │  秒级自动接管    │
                 │ ★心跳+超时双保  │  └───┬────────────┘
                 └───┬────────────┘      │
        是班长才跑：  │                   │ 不是班长：
        cron/IM/主动关怀/知识恢复 ◄──────┘ 不跑任何后台
                     │
       ★共享设施(每进程1份)             ★启动加锁：40 路并发冷启动
       ├─ NotifyHub: 1 个 LISTEN 连接    只建 1 份（asyncio.Lock，
       │  按 job 唤醒，丢通知轮询兜底     修复连接打爆的竞态 bug）
       ├─ TurnFetchPool: 8 连接共享
       │  ★失败回滚槽位，容量不缩水
       └─ 连接数 O(节点数) ≠ O(并发流)
                     │
              PG（advisory lock + 队列 + 事件表 + turn_events）
                     │                        ▲
                     │ 取任务                  │ ★AgentWorker 每 10 分钟
              ┌──────┴──────┐                 │ 分批 DELETE 过期事件
              │ agent-worker│                 │ （表不再无限增长）
              │  ×N         │─────────────────┘
              │ ★leader=False│  ★纯执行角色，永不参与选主
              └─────────────┘

   结果：api/worker 随便横向加；后台任务全集群恰好跑一份；
        连接数 70→13 有界；班长挂了秒级接管不停服
```
